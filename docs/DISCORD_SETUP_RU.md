# Как создать Discord-бота и пригласить его на сервер

[← Русский README](../README.ru.md) · [Установка на VPS](VPS_RU.md) · [Windows](WINDOWS_RU.md)

Эта инструкция подходит для **Discord Social Bot**. Она не требует программирования и не включает создание вебхуков вручную — при выбранном `REPOST_MODE=webhook` бот управляет ими самостоятельно, если есть права.

## 1. Создание приложения

1. Открой [Discord Developer Portal](https://discord.com/developers/applications) и войди в свой Discord-аккаунт.
2. Нажми **New Application**, введи название (например, `Discord Social Bot`) и подтверди создание.
3. Открой вкладку **Bot**. Здесь находится учётная запись бота, его имя и настройки.
4. В разделе токена нажми **Reset Token** / **View Token** (название кнопки зависит от интерфейса). Скопируй токен в защищённое место — он потребуется в приватном файле `.env`. Никому его не отправляй. Если токен утёк, сбрось его в Developer Portal и обнови `.env`.

**Токен — это пароль бота.** Для приглашения на сервер токен не нужен: не вставляй его в приглашения, сайты или GitHub.

## 2. Разрешение чтения текста сообщений

Оставаясь во вкладке **Bot**, найди **Privileged Gateway Intents** и включи **Message Content Intent**.

Без этого разрешения бот обычно не сможет прочитать ссылки из обычных сообщений и автоматически обработать их. В самом коде этот intent уже запрашивается. Дополнительные привилегированные intents для этой задачи не требуются.

## 3. Приглашение на Discord-сервер

1. В Developer Portal открой **Installation** или **OAuth2 → URL Generator** (зависит от версии интерфейса).
2. Для установки на сервер выбери scope **`bot`** и **`applications.commands`** — второй нужен для команды `/video`.
3. Выдай боту права только для тех функций, которые собираешься использовать:
   - **View Channels** — видеть текстовый канал.
   - **Send Messages** — отвечать в канале.
   - **Read Message History** — корректная работа с исходными сообщениями.
   - **Embed Links** — отправка предпросмотра.
   - **Attach Files** — загрузка видео/изображений.
   - **Manage Webhooks** — **необходимо для `REPOST_MODE=webhook`**.
   - **Manage Messages** — нужно **только если хочешь, чтобы бот удалял исходную ссылку** после подтверждённого репоста.
   - **Send Messages in Threads** — если бот должен работать в ветках обсуждений.
4. Скопируй созданную ссылку приглашения, открой её, выбери нужный сервер и подтверди авторизацию. Для добавления бота нужны соответствующие права управления сервером.
5. В разрешениях конкретных каналов убедись, что выбранные права не запрещены переопределениями ролей. **Administrator выдавать не нужно.**

Если `REPOST_MODE=reply`, право **Manage Webhooks** для основного сценария не требуется. Режим `reply` не удаляет исходное сообщение как режим `webhook`.

## 4. По желанию — ID сервера и каналов

Открой Discord → **Настройки пользователя → Дополнительно → Режим разработчика (Developer Mode)**.

- Правой кнопкой по значку сервера → **Копировать ID сервера** — это `TEST_GUILD_ID`. Он необязателен; помогает синхронизировать `/video` быстрее на указанном сервере.
- Правой кнопкой по текстовому каналу → **Копировать ID канала** — значения для `ALLOWED_CHANNEL_IDS`. Несколько ID разделяются запятыми. Пустая строка означает, что бот может обрабатывать сообщения во всех доступных каналах.

## 5. Настройка и первый запуск

Выбери [Windows](WINDOWS_RU.md), [Ubuntu VPS](VPS_RU.md) или [Altare](../ALTARE.md).

В корне проекта создай приватный файл `.env`:

```dotenv
DISCORD_TOKEN=PASTE_YOUR_TOKEN_HERE
REPOST_MODE=webhook
TRANSLATE_ENABLED=true
TEST_GUILD_ID=
ALLOWED_CHANNEL_IDS=
MYMEMORY_EMAIL=
```

Замени `PASTE_YOUR_TOKEN_HERE` реальным токеном. Не публикуй этот файл.

После установки зависимостей и FFmpeg выполни проверку `python check_runtime.py` и запусти `python bot.py` (внутри нужного Python-окружения).

В логах ожидаются сообщения `Slash commands synced` и `Connected to Discord`. Если глобальная slash-команда не появилась сразу, дождись синхронизации или укажи `TEST_GUILD_ID`.

## 6. Проверка в тестовом канале

1. Отправь одну публичную ссылку X/Twitter с видео или фото.
2. Убедись, что бот обработал ссылку и прислал медиа/предпросмотр.
3. Проверь GIF/анимацию и TikTok.
4. При `webhook` отдельно проверь удаление сообщения, состоящего из **одной ссылки**, только после успешного репоста.
5. Добавь к ссылке собственный текст — это сообщение не должно удаляться.
6. Проверь `/video` с поддерживаемой ссылкой.

Не все публикации доступны для скачивания; если сайт отказал или файл слишком велик, исходную ссылку следует сохранить.

## Если что-то не работает

Смотри [ошибки и решения](TROUBLESHOOTING_RU.md). Не публикуй токен или полный `.env` даже при обращении за помощью.
