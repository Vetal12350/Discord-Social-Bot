# Discord Social Bot 🇷🇺

**Discord Social Bot** — бесплатный бот с открытым исходным кодом, который автоматически оформляет публикации **X (Twitter)** и **TikTok** в каналах Discord. Бот самостоятельно получает доступные медиа, по возможности переводит подписи на русский и может отправлять сообщения через вебхуки от имени автора сообщения.

## Возможности

- Автоматически распознаёт публичные ссылки X/Twitter и TikTok, включая известные альтернативные домены для встраивания X.
- Отправляет изображения и совместимые видео MP4; для коротких анимаций пытается подготовить анимированный WebP/GIF с помощью FFmpeg.
- При включённом переводе пытается перевести текст на русский. Если перевод недоступен, сохраняет оригинальный текст.
- **Режим `webhook`**: публикует пост с именем и аватаром автора сообщения; удаляет исходное сообщение со *строго одной ссылкой* только после подтверждения успешной пересылки и при соблюдении условий безопасности.
- **Режим `reply`**: отвечает от лица бота без режима подмены оформления через вебхук.
- Команда `/video` — попытка загрузки MP4 по поддерживаемой ссылке.
- Ограничение числа одновременно выполняемых медиаопераций, размера вложений и временный кеш на диске.

> **Неофициальный проект.** Не связан с Discord, X, TikTok или Altare. Работа с медиа зависит от доступности сторонних сайтов; часть публикаций может быть недоступна. Бот не гарантирует скачивание всех ссылок и не обходит ограничения доступа к закрытому контенту.

## С чего начать

1. **[Создай приложение и бота в Discord Developer Portal](docs/DISCORD_SETUP_RU.md)** — получи токен, включи Message Content Intent, настрой права и пригласи бота на сервер.
2. **Выбери место запуска:**
   - [Windows (локальный ПК)](docs/WINDOWS_RU.md)
   - [Ubuntu VPS с круглосуточной работой и systemd](docs/VPS_RU.md)
   - [Altare / Pterodactyl](ALTARE.md)
3. В приватном файле `.env` заполни `DISCORD_TOKEN`, запусти `check_runtime.py` и только потом `bot.py`.
4. Проверь работу в отдельном тестовом текстовом канале.

**Требования:** Python 3.13/3.14; также Python 3.12 проверялся при развёртывании на Ubuntu 24.04. Нужны пакеты из `requirements.txt` и установленный `ffmpeg`/`ffprobe` с подходящими кодировщиками для анимации.

## Настройки .env

Скопируй [`.env.example`](.env.example) в `.env` **рядом с `bot.py`**:

```dotenv
DISCORD_TOKEN=PASTE_YOUR_TOKEN_HERE
REPOST_MODE=webhook
TRANSLATE_ENABLED=true
TEST_GUILD_ID=
ALLOWED_CHANNEL_IDS=
MYMEMORY_EMAIL=
```

| Переменная | Что делает |
| --- | --- |
| `DISCORD_TOKEN` | **Обязательная.** Токен Discord-бота; для старых конфигураций также поддерживается `DISCORD_BOT_TOKEN`. |
| `REPOST_MODE` | `webhook` (по умолчанию) или `reply`. |
| `TRANSLATE_ENABLED` | `true` / `false`. Перевод подписи на русский через внешние сервисы, когда доступен. |
| `TEST_GUILD_ID` | Необязательный ID сервера Discord для быстрой синхронизации slash-команд; без него синхронизация глобальная и может занять время. |
| `ALLOWED_CHANNEL_IDS` | Необязательный список ID каналов через запятую, например `123456789012345678,234567890123456789`; пустое значение означает все доступные каналы. |
| `MYMEMORY_EMAIL` | Необязательный контактный адрес для сервиса перевода MyMemory; не пароль и не API-токен. |

Права Discord подробно описаны в [инструкции по подключению](docs/DISCORD_SETUP_RU.md).

**Никогда не публикуй реальный `.env`**, токен, секреты вебхуков и журналы с чувствительными данными в GitHub Issues, чатах или скриншотах. Не запускай одновременно два экземпляра с одним токеном при переезде между серверами.

## Как пользоваться

- Просто вставь поддерживаемую ссылку в текстовый канал, где боту разрешён просмотр сообщений.
- Если в сообщении **только одна ссылка**, режим `webhook` может заменить его оформленным сообщением и удалить оригинал после подтверждения успешной пересылки.
- Если добавлен собственный комментарий, оригинальное сообщение сохраняется.
- При невозможности загрузить видео/GIF может остаться ссылка на оригинал — это ожидаемое безопасное поведение.
- Для ручной загрузки попробуй `/video`, передав URL публичной публикации.

## Безопасность и лицензия

Сохраняй токен только в приватном окружении, используй отдельного системного пользователя на VPS, минимальные права Discord и проверяй изменения перед обновлением рабочего экземпляра. CI проверяет синтаксис, импорты и имеющиеся тесты; не заменяет реальную проверку Discord.
