# Discord Social Bot на Altare

Архив для Generic Python / Docker / Pterodactyl, без systemd. Профиль: 3072 МиБ RAM, 150% CPU, 4096 МиБ диска. Действующие ограничения бота сохранены: одна медиаоперация, потоковые файлы, ограниченный временный кеш, быстрый WebP и максимум две конвертации GIF. Увеличивать настройки ради этого хостинга не требуется.

## 1. Файлы и зависимости

Остановите сервер в панели. В **Files / File Manager** загрузите `social-bot-altare.zip` и выберите **Unarchive / Extract** в корне сервера. Рядом должны лежать `bot.py`, `requirements.txt`, `config.py`, `.env.example` и остальные модули; дополнительной папки `social-bot-altare/` быть не должно. ZIP после распаковки можно удалить.

В **Startup** выберите обычный **Python 3.14** и главный файл **bot.py**. Если есть поле requirements file — `requirements.txt`. Python-шаблон Altare должен установить зависимости перед запуском; следите за выводом pip. Инструкция хостинга: [запуск Python-бота](https://altare.gg/de/help/discord-bots/deploy-python-bot).

Если автоматической установки нет и доступна именно shell-консоль, из корня сервера:

```sh
python -m pip install --user --no-cache-dir -r requirements.txt
```

Если контейнер уже использует виртуальное окружение, установите без `--user`. Обычная консоль работающего бота может передавать ввод в Python и не является shell: команды pip там не выполняются. В таком случае настройте установку requirements через Startup/шаблон панели.

Зависимости не изменены вслепую: все закреплённые версии установлены в отдельное локальное окружение **CPython 3.14.6**, проверены импорты и **192 теста**, включая настоящий FFmpeg/WebP/GIF. Для Linux x86_64/glibc проверено разрешение зависимостей и наличие совместимых CPython 3.14/abi3 wheels для нативных библиотек (aiohttp, Pillow, psutil, audioop-lts и их зависимостей) в [PyPI](https://pypi.org/). Чистый Python-пакет langdetect 1.0.9 успешно собран на 3.14. Зависимости занимают существенно меньше 4 ГиБ; кеши pip и Windows-окружения в ZIP не входят.

Это не запуск в настоящем контейнере Altare. Если выбранный образ не может установить зависимости, сохраните текст ошибки без секретов; поддерживаемый резерв — **Python 3.13**, на котором также выполнены тесты. Не заменяйте версии пакетов наугад. Проверка относится к обычному CPython с GIL, а не отдельной free-threaded-сборке 3.14t.

## 2. Токен

Создайте через файловый менеджер файл **.env** в том же корне, что и `bot.py` (либо скопируйте `.env.example` и переименуйте копию). Впишите настоящий токен только в приватном редакторе панели:

```dotenv
DISCORD_TOKEN=PASTE_YOUR_TOKEN_HERE
REPOST_MODE=webhook
TRANSLATE_ENABLED=true
```

Замените `PASTE_YOUR_TOKEN_HERE` своим токеном. Не вводите его в команду запуска/общую консоль, не присылайте в чат и не включайте в ZIP. Если панель предлагает защищённые переменные окружения, можно задать там эти же имена вместо `.env`. Переменные окружения имеют приоритет над `.env`.

Для старых установок сохранён `DISCORD_BOT_TOKEN`; задавайте одно имя. Если заданы оба, `DISCORD_TOKEN` имеет приоритет. Для ограничения каналов можно заполнить `ALLOWED_CHANNEL_IDS` из шаблона; `TEST_GUILD_ID` необязателен. Другие секреты и ручное создание Webhook не нужны. [Рекомендации Altare по хранению токена](https://altare.gg/es/help/discord-bots/store-bot-token-safely).

В Discord Developer Portal должен быть включён **Message Content Intent**. В тестовом канале нужны View Channel, Send Messages, Attach Files, Manage Webhooks, а для удаления исходника — Manage Messages и Read Message History. Administrator не требуется.

## 3. Проверка FFmpeg без SSH

FFmpeg и ffprobe нужны для X GIF, которые приходят от провайдера как MP4. Обычные совместимые MP4, фото и перевод работают без перекодирования. Python-пакет с названием ffmpeg не заменяет системные исполняемые файлы.

В **Startup** временно укажите главный файл **check_runtime.py**, запустите один раз и прочитайте вывод. Проверка не читает `.env`, не подключается к Discord, ничего не скачивает и не устанавливает. Она выводит Python, версии библиотек, наличие FFmpeg/ffprobe и кодировщиков libwebp_anim/GIF. Ожидается **GIF preflight: OK**, после чего этот проверочный процесс завершится — это нормально. Верните главный файл **bot.py**.

Если доступна shell, эквивалентные проверки:

```sh
python --version
python check_runtime.py
ffmpeg -version
ffprobe -version
```

Наличие FFmpeg именно в вашем образе Altare не подтверждено удалённо. Если выводится MISSING/NOT READY, выберите предоставляемый Altare образ с FFmpeg + ffprobe и поддержкой libwebp_anim либо попросите поддержку хостинга добавить эти системные инструменты. В обычном непривилегированном контейнере apt может быть недоступен. Бинарники в ZIP не включены: Windows-сборка на Linux не запустится. Пока инструментов нет, GIF сохраняет исходное сообщение и выдаёт отказ; обычные MP4/фото остаются доступны.

## 4. Запуск и ручная проверка

Главный файл: **bot.py**. Если панель позволяет указать полную команду, используйте:

```sh
python -u bot.py
```

Остановите прежнюю локальную/VPS-копию именно Social Bot с тем же токеном перед запуском новой. Не останавливайте другие проекты. Нажмите Start и дождитесь **Connected to Discord**. Веб-сервер, входящий порт, systemd и keep-alive сайт для этого бота не нужны.

В приватном Discord-канале отправляйте с интервалом более пяти секунд:

1. Обычное видео: `https://x.com/BrooklynNets/status/1349794411333394432` — вложение MP4, воспроизведение и звук, Webhook с вашим именем/аватаркой и текстом/переводом.
2. GIF: `https://x.com/TheRealGomba/status/2115453109325451455` — два кадра с повторением без Play; затем `https://x.com/4n_g3l_/status/2098128891999113682` — более длинная анимация. В клиенте Discord должны быть разрешены анимации.
3. Фото: `https://x.com/NASA/status/1546621080298835970`; затем видео/GIF через fixupx.com или fxtwitter.com — та же обработка.
4. Одиночная исходная ссылка удаляется только после полной подтверждённой пересылки. Комментарий + ссылка должен остаться. Одновременные алиасы одного поста не должны создавать вторую пересылку. Повтор позже в пределах двух минут может использовать кеш.

На непустой подписи есть жирный заголовок «Текст поста:»; при пустой его нет. Русский текст не переводится; при недоступном переводе остаётся оригинал. Бесплатные провайдеры и сами публикации могут быть недоступны. Воспроизведение, Webhook и удаление в настоящем Discord после развёртывания на Altare ещё нужно проверить; локальные тесты этого не подтверждают.

При обновлении сохраняйте `.env` отдельно и загружайте только файлы кода. Для отката остановите Social Bot, верните предыдущие файлы/requirements и запустите снова; токен в архив резервной копии не добавляйте. Никаких действий на сервере или изменений FunPayFlow при подготовке архива не выполнялось.
